# \# SIA-CENCINAI

# \*\*Sistema de Información y Analítica para CENCINAI\*\*

# 

# Proyecto desarrollado como práctica profesional del Instituto Tecnológico de Costa Rica (TEC), 

# en colaboración con el Centro de Educación y Nutrición y Centros Infantiles de Atención 

# Integral (CEN-CINAI), Ministerio de Salud de Costa Rica.

# 

# \## Descripción

# El SIA-CENCINAI busca sistematizar, gestionar y analizar la información generada por los 

# procesos institucionales de CEN-CINAI, iniciando con el subsistema de atención 

# interdisciplinaria. El proyecto combina ingeniería de software con herramientas de 

# inteligencia artificial para el desarrollo ágil del prototipo.

# 

# \## Stack tecnológico

# \- \*\*Frontend:\*\* Angular

# \- \*\*Backend:\*\* Node.js + ExpressJS

# \- \*\*Base de datos:\*\* OracleDB

# \- \*\*Contenedores:\*\* Docker

# \- \*\*Diagramas:\*\* PlantUML
