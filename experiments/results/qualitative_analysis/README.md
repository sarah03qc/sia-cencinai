# Qualitative analysis files

`qualitative_sample_metadata.json` records the original fixed-seed sample

`qualitative_replacements_metadata.json` records the two fixed-seed replacements

`qualitative_final_60_responses.csv` is the final sample used for manual review

`manual_verdicts_60.csv` stores the 60 B P M ratings

`manual_error_taxonomy_13.csv` stores the primary error labels for the 13 non-B responses

`analisis_cualitativo_crosswalk_60.csv` joins manual ratings, automatic metrics, retrieval, and LLM-as-a-Judge results
